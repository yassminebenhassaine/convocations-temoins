# Gestion des Convocations des Témoins

Application web en PHP pour la gestion des convocations des témoins et l'impression de l'ordre de comparution.

## 🛠️ Technologies
- PHP / MySQL
- HTML / CSS / JavaScript

## 🚀 Configuration
1. Importer `database.sql` dans phpMyAdmin.
2. Copier `config.example.php` vers `config.php`.
